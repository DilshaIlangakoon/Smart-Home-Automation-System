🏡 Smart Home Automation System
A Smart Home Automation System developed using ESP32 and IoT technologies to improve home comfort, energy efficiency, and safety through intelligent automation.

This project integrates multiple sensors and actuators to automate essential household functions such as lighting, temperature control, window blinds, water supply management, and flood detection. The system is monitored and controlled through the Blynk mobile application, providing users with real-time interaction and remote access.



📖 Project Overview

Modern homes require intelligent solutions that enhance convenience while reducing energy consumption and improving safety. This project addresses these challenges by implementing an affordable and efficient smart home automation system designed for the Sri Lankan context.

The system automatically responds to environmental conditions using IoT-enabled sensors, allowing users to experience a smarter, safer, and more energy-efficient home.

🏗 System Architecture

The Smart Home Automation System consists of an ESP32 microcontroller connected to multiple environmental sensors and output devices.

The ESP32 continuously collects sensor data, processes automation logic, and controls connected devices such as lights, fans, window blinds, water pumps, and alarms. Users can monitor and control the system remotely using the Blynk mobile application via Wi-Fi.
